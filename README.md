# 🎮 iFruit RolePlay BOT

Bot Discord GTA RP avec système de banque, inventaire et gestion d'objets.

## Commandes

| Commande | Description |
|---|---|
| `/banque` | Consulter son compte, déposer, retirer, voir l'historique |
| `/inventaire` | Gérer son inventaire, envoyer dans le véhicule/appart, donner |
| `/objet` | Créer, donner, supprimer des objets (Modérateurs) |
| `/moderation` | Configurer le bot, gérer les joueurs (Admins) |

## Installation Railway

1. Fork ce repo
2. Créer un projet sur Railway
3. Ajouter la variable d'environnement `TOKEN`
4. Deploy !
